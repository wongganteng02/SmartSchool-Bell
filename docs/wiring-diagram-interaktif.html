🚀 Alur Penggunaan v3.1
📋 Langkah Setup Suara & Jadwal
1
Salin file MP3 ke SD card dengan nama 001_NamaFile.mp3, 002_NamaFile.mp3, dst. Taruh di folder /mp3/.
2
Pasang SD card ke DFPlayer Mini, lalu nyalakan NodeMCU.
3
Buka dashboard di browser → masuk ke seksi Daftar Suara SD Card → isi No. Index + Nama Suara (samakan dengan nama file) → klik Daftarkan.
4
Tambah jadwal bel → pilih jam, hari, dan suara dari dropdown → simpan. Urutan pemanggilan suara bebas, tidak harus urut.
5
Bel otomatis berbunyi tepat di detik :00 sesuai jadwal yang disimpan.
💡 Contoh:
SD card: 001_Bel Masuk.mp3  →  Dashboard: Index 1, Nama Bel Masuk
Jadwal: 07:00 Senin–Jumat → Bel Masuk  |  13:00 Semua → Pulang ✅
